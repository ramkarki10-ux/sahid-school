फाइल कसरी सेभ गर्ने र स्थानीय रूपमा कसरी चलाउने? (Local Save & Usage Guide)

कम्प्युटरमा फाइल सुरक्षित राख्ने र अर्को डिभाइसमा सार्ने सजिलो तरिका

१. हालको कम्प्युटरमा फाइल कहाँ सेभ भएको छ?

यो सम्पूर्ण परियोजना तपाइँको कम्प्युटरको निम्न फोल्डरमा स्थायी रूपमा सुरक्षित (Saved) छ:

C:\Users\SNM\.gemini\antigravity\scratch\shahid-smriti-school

यस फोल्डरभित्रका कुनै पनि फाइल सम्पादन गरेपछि Ctrl + S थिच्दा सिधै सेभ हुन्छ।

२. नयाँ डेटा कसरी सेभ (Save) हुन्छ?

तपाइँले एडमिन प्यानल वा वेबसाइटबाट थप्नुभएको नयाँ विद्यार्थी, शिक्षक हाजिरी, गृहकार्य वा सूचना स्वतः तत्काल school.db मा सेभ हुन्छ।

कुनै छुट्टै सेभ बटन थिच्नु पर्दैन, प्रणालीले तत्काल डेटाबेस कमिट (Database Commit) गर्दछ।

३. पेनड्राइभ वा अर्को कम्प्युटरमा कसरी लैजाने?

१. माथिको "वेबसाइट ZIP डाउनलोड गर्नुहोस्" बटन थिच्नुहोस्।
२. डाउनलोड भएको Shahid_Smriti_School_Website_Complete.zip फाइललाई पेनड्राइभमा कपी गर्नुहोस्।
३. अर्को कम्प्युटरमा लगेर Extract All (अनजिप) गर्नुहोस्।

४. डाउनलोड गरेपछि कसरी चलाउने? (Commands)

नयाँ कम्प्युटरको टर्मिनल (PowerShell / CMD) मा प्रोजेक्ट फोल्डरभित्र गई यी दुई कमान्ड चलाउनुहोस्:

pip install -r requirements.txt
python run.py

त्यसपछि ब्राउजरमा http://localhost:3000/ खोल्नासाथ वेबसाइट तुरुन्तै चल्नेछ।
