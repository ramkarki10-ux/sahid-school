# सहिद स्मृति आवासीय माध्यमिक विद्यालय - वेब पोर्टल तथा विद्यालय व्यवस्थापन प्रणाली (MIS)
## Shahid Smriti Residential Secondary School Web Portal & Management System

**सहिद स्मृति आवासीय माध्यमिक विद्यालय**, इटहरी-१९, सुनसरी, कोशी प्रदेश, नेपालको आधिकारिक वेबसाइट तथा विद्यालय व्यवस्थापन प्रणाली (School MIS)।

---

## 🌟 मुख्य विशेषताहरू (Key Features)

### १. सार्वजनिक पोर्टल (Public Portal)
- **गृहपृष्ठ:** विद्यालयको परिचय, भिडियो, महत्त्वपूर्ण सूचनाहरू, पछिल्ला समाचार तथा गतिविधिहरू।
- **हाम्रो विद्यालय:** ऐतिहासिक पृष्ठभूमि, दृष्टिकोण, मिशन र प्रधानाध्यापकको सन्देश।
- **शिक्षक तथा कर्मचारी:** विषयगत शिक्षकहरूको सूची, योग्यता, अध्यापन अनुभव तथा फोटो।
- **दैनिक गृहकार्य सेवा:** कक्षा १ देखि १२ सम्मका विषयगत गृहकार्य तथा ७+ प्रश्नहरू सहितको प्रश्नावली।
- **परीक्षा नतिजा तथा लब्धांक पत्र (Marksheet):** सिम्बोल नम्बर, जन्ममिति र कक्षा छानेर टर्मिनल परीक्षाको डिजिटल मार्कसिट खोजी तथा प्रिन्ट।
- **प्रकाशन, ग्यालरी तथा सूचनाहरू:** गतिशील विधागत फिल्टर सहितका सूचना तथा फोटो/भिडियो ग्यालरी।
- **अनलाइन बिदा निवेदन (Online Leave Application):** विद्यार्थी तथा शिक्षकहरूले अनलाइनबाट बिदा फारम भर्ने सुविधा।
- **अभिभावक पोर्टल (Parent Portal):** विद्यार्थीको दैनिक हाजिरी, नतिजा र गृहकार्य अनुगमन।

### २. प्रशासनिक प्यानल (Admin Dashboard - MIS)
- **विद्यार्थी व्यवस्थापन:** विद्यार्थीहरूको दर्ता, व्यक्तिगत विवरण, कक्षा अनुसार खोजी, इडिट, डिलिट तथा Excel डाउनलोड।
- **शिक्षक व्यवस्थापन:** शिक्षकहरूको विवरण, फोटो अपलोड, सम्पर्क र अध्यापन तह व्यवस्थापन।
- **दैनिक गृहकार्य तथा प्रश्नावली व्यवस्थापन:** कक्षा १ देखि १२ अनुसार विषयहरूको डायनामिक ड्रपडाउन, कम्तिमा ७ वटा प्रश्नहरू सहितको प्रश्नावली सिर्जना, थपघट तथा सम्पादन।
- **कागजात प्रमाणीकरण (Document Verification):** स्थानान्तरण प्रमाणपत्र (TC), चारित्रिक प्रमाणपत्र आदि जारी तथा QR कोड प्रमाणीकरण।
- **परीक्षा नतिजा लेजर:** विषयगत अङ्क प्रविष्टि, GPA गणना र लेजर Excel निर्यात।
- **बिदा निवेदन अनुमोदन:** बिदा स्वीकृत वा अस्वीकृत गर्ने तथा Excel निर्यात गर्ने प्रणाली।
- **सम्पर्क सन्देश इन्बक्स:** वेबसाइटबाट प्राप्त गुनासो तथा सन्देशहरूको व्यवस्थापन।

## 🛠️ प्रविधिहरू (Technologies Used)
- **Backend:** Python 3.12+, FastAPI, Uvicorn
- **Frontend:** Jinja2 Templates, HTML5, Tailwind CSS, Lucide Icons
- **Database:** SQLite3 (`school.db`)
- **Excel Export/Import:** OpenPyXL, Pandas

## 🚀 परियोजना सञ्चालन गर्ने तरिका (Getting Started)

### आवश्यकताहरू:
- Python 3.10 वा सोभन्दा माथि
- Git

### १. रिपोजिटरी क्लोन गर्नुहोस्:
```bash
git clone https://github.com/ramkarki10-ux/sahid-school.git
cd sahid-school
```

### २. आवश्यक प्याकेजहरू इन्स्टल गर्नुहोस्:
```bash
pip install -r requirements.txt
```

### ३. सर्भर सुरु गर्नुहोस्:
```bash
python run.py
```

### ४. ब्राउजरमा खोल्नुहोस्:
- **वेबसाइट (सार्वजनिक):** [http://localhost:3000](http://localhost:3000)
- **प्रशासनिक प्यानल (Admin):** [http://localhost:3000/login](http://localhost:3000/login)
  - प्रयोगकर्ता नाम: `admin`
  - पासवर्ड: `password123`
