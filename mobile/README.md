# सहिद स्मृति आवासीय मा.वि. - क्रस-प्लेटफर्म मोबाइल एप (React Native / Flutter)
# Shahid Smriti Residential Secondary School - Mobile App Codebase

यो सहिद स्मृति आवासीय माध्यमिक विद्यालयको पूर्ण क्रस-प्लेटफर्म (iOS र Android दुवैमा चल्ने) मोबाइल एप्लिकेसनको कोडबेस हो। यसमा फेसबुक जस्तै डाइनामिक न्युज फिड, स्मार्ट विद्यार्थी हाजिरी ट्र्याकर, सूचना पाटी, शैक्षिक क्यालेन्डर र फोटो ग्यालरी एकीकृत गरिएको छ।

---

## 🌟 मुख्य विशेषताहरू (Key Features)

1. **फेसबुक जस्तै डाइनामिक न्युज फिड (Facebook-Style Dynamic Feed)**:
   - पोस्ट सिर्जना, फोटो अपलोड, र क्याटगोरी छनोट (सामान्य, घोषणा, उपलब्धि)।
   - इन्टर्याक्टिभ लाइक (मनपर्‍यो) बटन, प्रत्यक्ष लाइक काउन्ट अपडेट।
   - कमेन्ट सेक्सन (प्रत्यक्ष कमेन्ट थप्न र हेर्न मिल्ने)।
   - सूचनालाई सिधै फिडमा सेयर गर्न मिल्ने (Share Notice to Feed)।
   - पुल-टु-रिफ्रेस (Pull-to-Refresh) र लाइटबक्स फोटो जुम।

2. **स्मार्ट विद्यार्थी हाजिरी ट्र्याकर (Smart Attendance Tracker)**:
   - शिक्षक तथा एडमिनका लागि कक्षागत (१ देखि १२) विद्यार्थी हाजिरी गर्ने प्यानल (उपस्थित `P`, अनुपस्थित `A`, बिदा `L`)।
   - एकमुष्ट "सबै उपस्थित" वा "सबै अनुपस्थित" छनोट।
   - विद्यार्थी तथा अभिभावकका लागि व्यक्तिगत मासिक हाजिरी प्रतिशत तथा उपस्थिति रेकर्ड।

3. **सूचना पाटी (Notice Board)**:
   - क्याटगोरी अनुसार सूचनाहरू (सामान्य, परीक्षा, भर्ना, बिदा)।
   - संलग्न कागजात (PDF/Word) डाउनलोड लिङ्क।
   - फिडमा १-क्लिक सेयर सुविधा।

4. **शैक्षिक क्यालेन्डर (Academic Calendar)**:
   - वार्षिक शैक्षिक क्यालेन्डर, बिदा, परीक्षा र कार्यक्रमहरूको तालिका।

5. **फोटो तथा कार्यक्रम ग्यालरी (Photo Gallery)**:
   - विद्यालयका ऐतिहासिक तथा वार्षिक कार्यक्रमहरूका तस्बिरहरू र फुलस्क्रिन दर्शक।

6. **डिजिटल परिचयपत्र तथा प्रोफाइल (Digital ID & Profile)**:
   - प्रयोगकर्ताको डिजिटल स्कुल आईडी कार्ड (नाम, रोल, युजरनेम, फोन, सक्रिय स्थिति)।
   - एडमिन, शिक्षक, विद्यार्थी र अभिभावकका लागि छुट्टाछुट्टै लगइन तथा अधिकार।

## 🚀 मोबाइल एप कसरी चलाउने? (How to Run)

### १. पूर्वतयारी (Prerequisites)
- [Node.js (v18 वा पछिल्लो)](https://nodejs.org/)
- मोबाइलमा परीक्षणका लागि गुगल प्ले स्टोर वा एप्पल एप स्टोरबाट **Expo Go** एप डाउनलोड गर्नुहोस्।

### २. डिपेन्डेन्सी इन्स्टल गर्नुहोस् (Install Dependencies)
```bash
cd mobile
npm install
```

### ३. एप सुरु गर्नुहोस् (Start App)
```bash
npm start
```
यसपछि टर्मिनलमा एउटा **QR Code** देखिनेछ।
- **Android**: आफ्नो मोबाइलको `Expo Go` एप खोलेर QR कोड स्क्यान गर्नुहोस्।
- **iOS**: iPhone को क्यामेरा एपबाट QR कोड स्क्यान गरी Expo Go मा खोल्नुहोस्।
- **Web**: ब्राउजरमा जाँच्न `w` थिच्नुहोस्।
- **Android Emulator**: `a` थिच्नुहोस्।

## 📦 एन्ड्रोइड APK बनाउने तरिका (Build Android APK)

Expo Application Services (EAS) प्रयोग गरेर सिधै इन्स्टल गर्न मिल्ने `.apk` फाइल बनाउन सक्नुहुन्छ:

```bash
# EAS CLI इन्स्टल गर्नुहोस्
npm install -g eas-cli

# EAS मा लगइन गर्नुहोस्
eas login

# Android APK बिल्ड सुरु गर्नुहोस्
npm run build:apk
```

## 🌐 ब्याकएन्ड जडान (Backend Connection)

यो मोबाइल एप प्रत्यक्ष रूपमा लाइभ ब्याकएन्डसँग जोडिएको छ:
- **Production Backend URL**: `https://sahid-school.vercel.app`
- **लोकल विकासका लागि**: `mobile/src/services/api.ts` मा `API_BASE_URL` लाई आफ्नो लोकल कम्प्युटरको IP एड्रेस (उदा: `http://192.168.1.100:8000`) मा परिवर्तन गर्न सकिन्छ।
